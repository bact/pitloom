# Security Policy

Only the latest release on [PyPI](https://pypi.org/project/pitloom/) is
supported (Pitloom is pre-1.0).

## Reporting a Vulnerability

Do **not** open a public issue. Instead, use:

- [GitHub Security Advisories](https://github.com/bact/pitloom/security/advisories/new)
  (preferred)
- Email <suriyawa@tcd.ie>

Include a description, reproduction steps, and affected version(s).
You'll get an acknowledgment within a few days.
