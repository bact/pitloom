# Message codes

See also: [Messages and codes](messages.md) for the line grammar, what a code
guarantees and when to trust one.

states it: what it means, what Pitloom did and what to do about it. This page
indexes the codes; each code's section is on the page its link names, one
page per topic. The pages are generated from the catalogue, so they say what
this version prints.
